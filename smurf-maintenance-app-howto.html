Maintenance App
How to review and update requests
Use the queue to triage work, then document assignment, status, work order, and maintenance follow-up.
How to use the Maintenance App
1

Find the Request

Use Search and the Building, Status, and Urgency filters to narrow the maintenance queue.

2

Open the Request Card

Select the request card to load the exact SharePoint record into the Maintenance Assignment screen.

3

Review the Request

Check requester, location, asset, urgency, issue summary, impact notes, and SMURF reported conditions.

4

Assign an Owner

Select the responsible person in Assigned To. If the existing assignment is unchanged, preserve the saved name.

5

Set Maintenance Status

Choose the status that matches the actual work state.

6

Enter Work Order

Add the work-order number when applicable. Leave blank if no work order exists.

7

Document Notes

Record findings, work performed, support needed, parts, follow-up, or closure details.

8

Submit Update

Select Submit Maintenance Form. The app saves the maintenance fields, refreshes SharePoint, and confirms success.

Status guide
Waiting for AssignmentNo owner has been assigned yet.
In progressAn owner is actively investigating, repairing, coordinating, or otherwise working the request.
Follow-Up RequiredAdditional inspection, parts, scheduling, vendor support, or other follow-up remains.
CompletedMaintenance work and required documentation are complete.
