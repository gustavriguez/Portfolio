SMURF
Shared Maintenance Urgency-Based Request Form
How to submit a maintenance request
Answer what you observe. SMURF calculates the initial urgency automatically.
Emergency situations: Submit SMURF for documentation/work-order tracking, but also contact the appropriate team through RelayX radio or the site emergency communication process.
How to use the Request App
1

Select Department + Building

Choose where the issue belongs. Department and building are selected independently.

2

Answer General Questions

Complete every Yes/No question based on the current condition.

3

Choose Concern Type

Mechanical, Utilities/Facilities, Safety/EHS, Quality/Process Impact, or Controls/Electrical/Automation.

4

Answer Concern Questions

Complete all questions for the selected concern type. Do not try to manually choose urgency.

5

Enter Request Details

Add room/area, asset number if known, issue summary, details, and impact notes.

6

Add Attachments

Include useful photos, screenshots, alarms, or other supporting files when available.

7

Review

Check location, concern type, issue details, reported conditions, and SMURF initial priority.

8

Submit

Submit the request. Start a new request only after the current one is confirmed submitted.

What makes a good request?

Use factual descriptions

  • What is happening?
  • Where is it happening?
  • What equipment or asset is involved?
  • When did it start?
  • What is the impact on work, production, quality, utilities, facilities, or safety?

Let SMURF assign initial priority

  • Requester does not select urgency.
  • Yes answers are retained as reported conditions.
  • Urgency is calculated from configured SMURF logic.
  • Maintenance can review the full request and reported conditions after submission.
